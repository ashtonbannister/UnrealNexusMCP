# Hayba material receipt v2 - 2026-11-12

The v2 candidate restores the scalar, vector and texture material-instance routes using a fixed typed selector, exact resolved instance identity, no automatic retry, and native readback. Scalar and vector comparisons use binary32 bits; a three-component vector supplies alpha 1. Texture writes require the requested path to resolve to that exact texture object and report pointer/readback identity. A successful normalized result requires verified readback, a successful save receipt and a clean package. Partial writes and errors are retained; they are not rollback.

The combined patch is based on Hayba `b69ed11011f89aed3c444a50bd2331b99551c777`. `patches/hayba-nexus-material-receipt-v2.patch` has SHA-256 `26fcc993736bd496c4d14ff91ec0c2b4043e85f0165ef342ac3b5ad9dcac04e9`. It includes the prior no-retry delta and adds a fixed read-only `material_nexus_identity` command that reports a fresh nonce, editor PID, project and native receipt marker. This replaces the coordinator's Python identity probe for this patch; it does not bypass Hayba's Python policy or expose arbitrary Python through Nexus.

On a separate UE 5.8.4 test host, the patched native plugin and TypeScript server compiled. A disposable material and instance were created and saved only inside that host. One scalar write through the candidate Nexus coordinator returned the exact requested and resolved instance, `requested_value: 0.3`, native `observed_value: 0.30000001192092896`, matching float32 bits `3e99999a`, `verified: true`, `saved: true` and `dirty: false`. This is a native save receipt, not an independent reload check. Vector and texture were source/fixture checked but not individually live-tested.

The first write attempt was refused before dispatch because Hayba's policy blocked its Python identity probe. A later pre-dispatch refusal exposed a schema-pattern mismatch; both were fixed before the successful call. Full-tool mode also failed to list tools because an unrelated custom schema cannot be represented as JSON Schema. The tested host instead explicitly preloaded only the material pack through Hayba settings; Nexus did not invoke a dynamic pack loader or generic route. The synthetic editor logged that its bundled MCP sidecar was absent; the test used the separately launched staged stdio server.
