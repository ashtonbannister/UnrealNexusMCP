## Fixture and native gates

For each independently admitted child, compare eligible providers at immutable pins, define exact input/target/authority and validated output budgets, then exercise pre-dispatch refusal, malformed/missing native acknowledgement, partial execution, cross-client ownership, reset/epoch change, timeout and cancellation. A capture must correlate actual image bytes and dimensions to the requested world/window; an input must correlate observed effect and any outstanding hold to its owner. Native acceptance records the loaded provider and engine, desktop/window or XR environment, source/patch hashes, target epoch, retained receipts and explicit cleanup. Source review and fixture success remain distinct from actual editor or device evidence.
