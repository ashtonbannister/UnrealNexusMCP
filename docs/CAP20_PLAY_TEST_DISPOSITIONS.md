## Limits and next work

Only the named slices above were compared. Source records may contain additional selectors, behavior or modes; do not set a whole-record `implemented`, `equivalent`, or `rejected` disposition without reviewing those variants. EngineWire's [metadata-only trace analysis](https://github.com/ChiR24/Unreal_mcp/blob/5a17d6d343ef9b40a509068cff73f1bfb4509815/plugins/EngineWire/Source/EngineWire/Private/Domains/Insights/McpInsightsTraceAnalysis.cpp#L13-L53) is a candidate comparison, but its `analyze_trace` selector is not an independently enumerated exact row in the current ledger. Claireon automation and PIE trace capture declarations are internal rows, not public MCP tools; remaining variants and native qualification remain open. Physical/UI input, XR and relay are separate CAP-18B intents; source selection, fixture checks and native evidence must not be conflated.

All reviewed claims above are pinned-source and current-catalog evidence. No plugin was compiled, no live machine hold, input, automation run or trace was exercised, and no source record is newly exposed.
